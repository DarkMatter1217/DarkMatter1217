### Research

**A Claim-Centric Multi-Source Verification Architecture for Reducing Hallucinations in Retrieval-Augmented Generation**<br/>
*Amity Journal of Computational Sciences*, Vol. 10, Issue 1 (2026) · [PDF](https://img.amizone.net/AzureFileHandler.ashx?FileName=amitywebsite/userfiles/aijem/a30ec572.pdf) · [Code](https://github.com/DarkMatter1217/ARA)

Instead of trusting whatever a RAG system retrieves, ARA splits an answer into separate claims and checks each one against independent web evidence. On 496 hand-labeled claims it gave about 80% fewer false "supported" labels than a standard RAG setup.
